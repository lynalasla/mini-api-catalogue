┌──────────────────────────────────────────────────────────────┐
│  EN CAS DE PROBLÈME                                          │
└──────────────────────────────────────────────────────────────┘

  📚 Consultez : RESTAURATION_GUIDE.md
  
  Problèmes courants :
  
  ❌ "Fichier non trouvé"
     → Vérifiez que vous êtes à la racine : pwd
  
  ❌ "Unknown argument imageUrl"
     → Utilisez .cjs pas .js : restore-database.cjs
  
  ❌ "Cannot find module exceljs"
     → npm install exceljs --save-dev
  
  ❌ "Cannot connect to database"
     → docker-compose up -d && sleep 30
